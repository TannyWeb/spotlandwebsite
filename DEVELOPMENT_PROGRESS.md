# Spotland Community Hub - Progress Snapshot

## Tech Stack
- Astro (Frontend)
- Sanity.io (CMS)
- Tailwind CSS
- shadcn/ui (Components)

## Design System (Current)
- Primary: #26a1ab (Teal)
- Accent: #d97706 (Soft Terracotta/Muted Orange)
- Backgrounds: bg-slate-50 or bg-teal-50/50 for sections.
- Radius: rounded-3xl (24px) for organic, community feel.
- Shadows: Soft, diffused shadows instead of borders.

## Completed Features
- Image pipeline from Sanity with Unsplash placeholders.
- Service Detail pages with Sanity Portable Text.
- Floating 'Ready to Join Us' CTA banner with teal-to-terracotta gradient.
- Removal of 'boxy' layouts in favor of open, organic lists.
